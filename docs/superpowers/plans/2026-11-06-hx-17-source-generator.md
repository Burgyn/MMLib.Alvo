# HX-17 — Generated typed entities — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A host that marks its descriptor (or a Management API snapshot of it) `AlvoDescriptor="true"` gets, at build time, one `sealed partial class` wrapper per entity, an enum per `enum` field, a role-constant class and a typed patch per entity — and a boot that warns when a generated class no longer fits the live schema.

**Architecture:** An `IIncrementalGenerator` in `MMLib.Alvo.Analyzers` (netstandard2.0, packed by `MMLib.Alvo` at `analyzers/dotnet/cs`, E6) reads `AdditionalFiles` whose `AlvoDescriptor` metadata is `true`, parses them with its own dependency-free JSON reader into an equatable model (`DescriptorModel`), and emits C# from that model only — so an unrelated edit reuses every cached step. Generated classes implement HX-05's `IAlvoEntity` protocol (`AlvoRecord Record` + `(AlvoRecord)` constructor, `[AlvoEntity]`, `[AlvoField]`, `[AlvoEnumValue]`), so `As<T>()`, typed reads/writes, `Entity<T>` and lambda translation already work on them; each property reads through one new public core helper, `AlvoRecordExtensions.Get<T>`, so a wrapper and `As<T>()` share one conversion. At boot, an internal `GeneratedEntityCheck` finds generated classes (by `[GeneratedCode("MMLib.Alvo.Analyzers", …)]`) and logs `GeneratedEntityStale` for each one the boot's schema no longer fits, reusing HX-05's `ShapeMapping`.

**Tech Stack:** Roslyn 4.14 incremental generators (netstandard2.0, `EnforceExtendedAnalyzerRules`), xUnit v3 on MTP, Shouldly, Verify (string snapshots of generated sources), CsCheck, PublicApiGenerator, SQLite + PostgreSQL 16 (Testcontainers), Astro/Starlight docs with executed snippets.

**Spec:** `docs/superpowers/specs/2026-10-14-host-extensibility-design.md` — §7 *HX-17* (scope, docs, acceptance (1)–(6)); §2.3 **X18** (class, not struct, wrappers); §3.2 D2 (`AlvoSaved<T>.Old` nullable, no `!`); §3.3 **E6** (analyzer project packed in the core nupkg, own JSON reader, packed consumer on the minimum SDK) and *HX-10 settled details* (15)–(18); §4.3 *HX-05 settled details* (11), (13), (14), (16), (21), (28), (36); §4.5 *HX-07 settled details* (19), (52); §5 row `17` "(generator output only)"; Appendix A M11, M22. ## Review Focus

1. **A wrapper made by `Create(...)` is read before it is stored** (`ticket.Id`). Expected: `InvalidOperationException` naming field `id` and saying the record has no such field yet — never a `KeyNotFoundException` or `Guid.Empty`. Pinned by `GeneratedWrapperTests.Reading_the_id_of_an_unsaved_wrapper_names_the_missing_field` (Task 3).
2. **A field or enum value whose name is not a C# identifier** (`"1st_call"`, `"in-progress"`, `"class"`, a field equal to the class name or to `Record`). Expected: a compiling, stable name (`_1stCall`, `InProgress`, `@class` parameter / `Class` property, `RecordValue`), the raw name kept in `[AlvoField]`/`[AlvoEnumValue]`. Pinned by `GeneratedNamesTests.Hostile_names_compile_and_keep_their_raw_text` (Task 3).
3. **A consumer with `GenerateDocumentationFile`, `TreatWarningsAsErrors` and `Nullable=enable`.** Expected: generated code adds no warning. Pinned by `GeneratedCompileTests.Generated_code_compiles_warning_free_under_strict_settings` (Task 4) and by the packed consumer (Task 7).
4. **A Management API snapshot instead of a descriptor** (`{"project":…,"revision":…,"descriptorJson":"…"}`, the body of `GET …/projects/{p}/descriptor`). Expected: the same output as the descriptor it wraps. Pinned by `DescriptorReaderTests.A_management_snapshot_reads_as_the_descriptor_it_carries` (Task 1) and `AlvoEntityGeneratorTests.A_snapshot_and_its_descriptor_generate_identical_sources` (Task 4).
5. **A hidden, `events.exclude`d or `json` field.** Expected: no typed property (a read never carries a hidden field, and `As<T>()` refuses a record missing a mapped one; a handler mapping an excluded field is refused at boot by HX-05), still reachable as `x.Record["field"]`, and named in the class's `<remarks>`. ## Decisions (not settled by the spec; one line each, cost if wrong)

1. **Own JSON reader** (`DescriptorJson`, ~200 lines, RFC 8259 recursive descent), not a packed `System.Text.Json` — E6 says "bundles its own reader copy"; packing STJ next to an analyzer conflicts with the IDE's copy. Cost: a parser bug → a parity property against STJ guards it.
2. **One public helper, `AlvoRecordExtensions.Get<T>(record, field)`** — deviation from §5 row 17 "(generator output only)": generated code lives in the consumer and can call only public API, and a second (emitted) copy of `RecordValue`'s conversions would drift from `As<T>()`. Precedent: STJ's public generator helpers. Cost: one permanent public member.
3. **Class name = PascalCase of the entity name, singularized** by three rules only (`ies`→`y`, `sses`→`ss`, a trailing `s` not after `s`, `u` or `i` dropped): `work_orders`→`WorkOrder`, `categories`→`Category`, `status`→`Status`. A collision → `ALVO2002`, entity skipped. Cost: changing the rule later renames consumer types (breaking).
4. **Hidden (`true` or CEL), `events.exclude`d and `json` fields get no property** (Review Focus 5). Cost: no typed access to them.
5. **Wrappers are immutable**; `Create(...)` puts every declared parameter (nulls included) into the record, and the typed create leaves nulls out (HX-07 (19)). Updates go through the generated `{Class}Patch`, which has setters only for caller-writable fields. Cost: no `With` helpers (host uses `Record.With`).
6. **Namespace** = `AlvoNamespace` metadata, else `build_property.RootNamespace`, else `Alvo.Generated`. Cost: none.
7. **Roles** → `public static class {Project}Roles` (`help-desk`→`HelpDeskRoles`) with `Anon`, `Authenticated`, `Admin` and every `auth.roles` entry, deduplicated, in that order. Cost: none.
8. **Snapshot input** = the Management API descriptor response, recognised by a top-level string `descriptorJson`; no CLI is added (a `curl` line in the docs). Cost: a future envelope change needs a reader change.
9. **The boot check warns, never refuses** (`GeneratedEntityStale`); a registered typed handler keeps HX-05's boot refusal. Dashboard-first stays up (spec I7 precedent). Cost: a stale, unregistered class fails at its first `As<T>()` instead of at boot.
10. **Discovery** = the entry assembly and every assembly it references transitively that references `MMLib.Alvo`, types carrying `GeneratedCode` tool `MMLib.Alvo.Analyzers` + `[AlvoEntity]` + `IAlvoEntity`. Cost: a generated class in a dynamically loaded plugin is not checked.
11. **Ignored descriptor keys:** everything the model does not read (HX-14/15/18's `steps`, `stateMachine`, `timers`, `functions.*.input`, `automation`) — the reader is tolerant; generating function input types is a follow-up issue. `dynamicEntities` (runtime types) are not generated; an entity with `storage: dynamic` is. Cost: none until a host asks.
12. **Field order** = descriptor order, managed columns first (`id`, `tenant_id`, audit four). Cost: none.
13. **Singular (ruling G6', supersedes the three rules of Decision 3):** a last word in the table {`statuses`→`status`, `buses`→`bus`, `people`→`person`, `children`→`child`, `data`→`data`} is replaced; else `ies`→`y`; else `(sses|xes|zes|ches|shes)` drops `es`; else a trailing `s` is dropped unless the name ends in `ss`, `us` or `is`. Accepted quirks: `news`→`New`, `movies`→`Movy`, `series`→`Sery`, `quizzes`→`Quizz`, `aliases`→`Aliase`. Cost: changing it later renames consumer types.
14. **Property nullability = `!field.Nullable`** (the model folds `nullable ?? !required` and `virtual` in), exactly what `ShapeMapping.Nullability` checks — not the literal "required and not virtual", under which `required: true, nullable: true` would fail `As<T>()`. Cost: none.
15. **`GeneratedCode` version read by reflection:** one cached `AssemblyInformationalVersionAttribute` read (the `+sha` cut), off the cached-model path — the lesser breach of "no reflection", since no reflection-free read of an assembly attribute exists and a build-time constant would need a MinVer-ordered generated source. Cost: none.
16. **Reserved member names:** a property, enum member or role constant equal to a member `object` (or, for enum members, `System.Enum`) already has, or to `Record`/`Patch`/`Create` on the class, is suffixed `Value`; duplicate field keys keep the last definition once. Cost: none.
17. **Implicitly imported type names (ruling G17):** a class name equal to a type the SDK's implicit global usings (or the web SDK's) bring in — `Task`, `ValueTask`, `TaskStatus`, `Type`, `File`, `Path`, `Timer`, `Version`, `Guid`, `List`, `LogLevel`, `Host`, … (`CSharpNames.ImplicitlyImportedTypeNames`) — is suffixed `Entity` (`tasks`→`TaskEntity`); a `{Class}{Property}` enum name equal to one is suffixed `Enum` (`values.task`→`ValueTaskEnum`). No listed name ends in `Patch` or `Roles`, so patch and roles names cannot clash (pinned). Otherwise `async Task` stops compiling in every host file under the generated namespace (the default is `RootNamespace`) and is ambiguous where it is imported. Cost: adding a name to the list later renames a consumer type (breaking).

```csharp
internal readonly struct EquatableArray<T>(ImmutableArray<T> items) : IEquatable<EquatableArray<T>>, IEnumerable<T>
    where T : IEquatable<T>
{
    private readonly ImmutableArray<T> _items = items;

    public int Count => _items.IsDefault ? 0 : _items.Length;

    public T this[int index] => _items[index];

    public bool Equals(EquatableArray<T> other) => AsSpan().SequenceEqual(other.AsSpan());

    public override bool Equals(object? obj) => obj is EquatableArray<T> other && Equals(other);

    public override int GetHashCode()
    {
        var hash = 17;
        foreach (var item in AsSpan())
        {
            hash = unchecked((hash * 31) + (item?.GetHashCode() ?? 0));
        }

        return hash;
    }

    public ReadOnlySpan<T> AsSpan() => _items.IsDefault ? ReadOnlySpan<T>.Empty : _items.AsSpan();

    public IEnumerator<T> GetEnumerator() => ((IEnumerable<T>)(_items.IsDefault ? ImmutableArray<T>.Empty : _items)).GetEnumerator();

    IEnumerator IEnumerable.GetEnumerator() => GetEnumerator();
}
```

```csharp
/// <summary>One field of the record as a <typeparamref name="T"/>, converted the way <see cref="As{T}"/> converts it.</summary>
/// <remarks>
/// Generated typed classes read every property through this method. A whole number, an id or a day stored as text, an
/// instant and an enum's declared value are converted; a null answers <see langword="default"/> when
/// <typeparamref name="T"/> takes null.
/// </remarks>
/// <exception cref="InvalidOperationException">
/// The record has no such field, holds null where <typeparamref name="T"/> cannot, or a value it cannot take — the
/// message names the field, never the value.
/// </exception>
public static T Get<T>(this AlvoRecord record, string field)
{
    ArgumentNullException.ThrowIfNull(record);
    ArgumentException.ThrowIfNullOrWhiteSpace(field);
    if (!record.TryGetValue(field, out var raw))
    {
        throw new InvalidOperationException(
            $"The record has no field '{field}'. A record not stored yet has no id or audit columns; a read leaves out a field the caller may not see.");
    }

    return raw is null ? NullOf<T>(field) : (T)(RecordValue.Convert(raw, typeof(T)) ?? throw Unheld<T>(field, raw));
}
```

`NullOf<T>` returns `default!` when `default(T) is null` (reference type or `Nullable<>`), else throws `Field '{field}' is null, but {typeof(T).Name} cannot hold null.`; `Unheld<T>` — `Field '{field}' holds {a/an} {raw.GetType().Name}, which {T} cannot take.` `Convert` unwraps `Nullable<>`, then: an enum target → `EnumMap.Of(target).MemberOf(text)` for a string, the value itself when already that enum; otherwise today's `Scalar`. `RecordValue.Held` is rewritten to call `Convert` (`RecordUnreadableException` paths unchanged).

```csharp
[Generator(LanguageNames.CSharp)]
public sealed class AlvoEntityGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        var rootNamespace = context.AnalyzerConfigOptionsProvider.Select(static (options, _) =>
            options.GlobalOptions.TryGetValue("build_property.RootNamespace", out var value) && value.Length > 0 ? value : "Alvo.Generated");

        var files = context.AdditionalTextsProvider
            .Combine(context.AnalyzerConfigOptionsProvider)
            .Select(static (pair, ct) => DescriptorFile.From(pair.Left, pair.Right.GetOptions(pair.Left), ct))
            .Where(static file => file is not null)
            .Select(static (file, _) => file!.Value)
            .WithTrackingName(Steps.Files);

        var models = files
            .Combine(rootNamespace)
            .Select(static (pair, _) => DescriptorReader.Read(pair.Left.Path, pair.Left.Text, pair.Left.Namespace ?? pair.Right))
            .WithTrackingName(Steps.Models);

        context.RegisterSourceOutput(models.Collect(), static (spc, results) => Emit(spc, results));
    }

    private static void Emit(SourceProductionContext context, ImmutableArray<DescriptorReadResult> results)
    {
        var taken = new HashSet<string>(StringComparer.Ordinal);
        foreach (var result in results.OrderBy(static r => r.File, StringComparer.Ordinal))
        {
            if (result.Model is not { } model)
            {
                context.ReportDiagnostic(Diagnostic.Create(GeneratorDiagnostics.Unreadable, Location.None, result.File, result.Error));
                continue;
            }

            EmitModel(context, model, taken);
        }
    }

    private static void EmitModel(SourceProductionContext context, DescriptorModel model, HashSet<string> taken)
    {
        AddOnce(context, taken, model.File, $"{model.Namespace}.{CSharpNames.Pascal(model.Project)}Roles", RolesEmitter.Emit(model));
        foreach (var entity in model.Entities)
        {
            AddOnce(context, taken, model.File, $"{model.Namespace}.{entity.ClassName}", EntityEmitter.Emit(model, entity));
        }
    }

    private static void AddOnce(SourceProductionContext context, HashSet<string> taken, string file, string typeName, string source)
    {
        if (!taken.Add(typeName))
        {
            context.ReportDiagnostic(Diagnostic.Create(GeneratorDiagnostics.Collision, Location.None, file, typeName));
            return;
        }

        context.AddSource($"{typeName}.g.cs", SourceText.From(source, Encoding.UTF8));
    }
}
```

```csharp
internal static class GeneratedEntityCheck
{
    internal const string GeneratorName = "MMLib.Alvo.Analyzers";

    internal static IReadOnlyList<Type> Discover(Assembly? root)
    {
        if (root is null)
        {
            return [];
        }

        var core = typeof(GeneratedEntityCheck).Assembly.GetName().Name;
        var seen = new HashSet<string>(StringComparer.Ordinal);
        var pending = new Stack<Assembly>([root]);
        var found = new List<Type>();
        while (pending.TryPop(out var assembly))
        {
            if (!seen.Add(assembly.FullName ?? assembly.GetName().Name!))
            {
                continue;
            }

            found.AddRange(GeneratedIn(assembly));
            foreach (var loaded in assembly.GetReferencedAssemblies().Where(Candidate).Select(TryLoad).OfType<Assembly>())
            {
                if (loaded.GetReferencedAssemblies().Any(name => name.Name == core))
                {
                    pending.Push(loaded);
                }
            }
        }

        return found;
    }
```
