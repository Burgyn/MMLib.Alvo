# F6 README + Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a product-grade README and an Astro Starlight documentation site (`website/`), deployed to GitHub Pages, whose reference section is generated from the code, whose descriptor snippets are validated in ring0, and whose HTTP exchanges are captured from a real host at build time.

**Architecture:** `website/` is an Astro + Starlight site outside `MMLib.Alvo.slnx`, themed from the admin dashboard's design tokens (extracted from `alvo.css` at build, not copied). A new console tool, `tools/MMLib.Alvo.DocsGen`, runs as the site's `prebuild` step. It reads `schema/project.schema.json`, reflects over the shipped assemblies and their XML docs, and boots the real standalone host in-process (TestServer): once over `examples/vehicle-registry` to capture the Data API OpenAPI document, the CEL catalog, the capabilities answer and the Management API route table, and once per `*.exchange.json` spec to capture the request/response pairs the pages show. It writes gitignored Markdown, JSON and the served schema copy, then `llms.txt`/`llms-full.txt`. Descriptor snippets live as `*.alvo.json` files that ring0 validates and applies.

**Tech Stack:** Astro 7.3.8, @astrojs/starlight 0.42.6, starlight-links-validator 0.27.0, starlight-openapi 0.27.0, rehype-mermaid 3.0.0 (build-time SVG via Playwright 1.64.0), Astro Fonts API (fontsource provider: Public Sans, IBM Plex Mono), @axe-core/playwright 4.13.0, lighthouse 13.5.0; .NET 10, xUnit v3 on MTP, Shouldly; GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-10-09-f6-docs-site-design.md` (binding, revised 2026-10-09 after the docs/IA and UX reviews). Executors read the spec and this plan together.

## Review Focus

1. **Relative repo links in repo-sourced pages** (`CHANGELOG.md`, `CONTRIBUTING.md` link `docs/…`, `CLAUDE.md`, `examples/…`). Expected: they become `https://github.com/Burgyn/MMLib.Alvo/blob/main/<path>`, and `#anchors` and absolute URLs stay untouched. Otherwise the link validator fails the build, or readers hit 404s. Pinned by `RepoMarkdownPageTests.Relative_repo_links_become_github_urls` (Task 11).
2. **Schema/XML description text containing Markdown- or HTML-significant characters** (`before* … after*`, `a || b`, `<T>`, `{{@user.email}}`, a literal `|` inside a table cell). Expected: it renders as the literal text. No accidental emphasis, no broken table, no swallowed tag. Pinned by `MdTests` and `SchemaReferenceRendererTests.Description_text_renders_literally` (Task 5).
3. **Schema shapes beyond the happy path:** a `$ref` reused under many keys or cyclic, a boolean `false` subschema (the reserved `users` entity, conditional `then.properties.x: false`), a map (`additionalProperties`), an array of objects, `oneOf` variants that share key names, and an `if/then` the renderer does not recognise. Expected: the walk terminates, each key appears once per page with a unique anchor, a reserved name is stated, variant keys are merged, and an unrecognised conditional fails a ring0 test instead of vanishing. Pinned by `SchemaWalkerTests` + `RealSchemaTests` (Task 5).
4. **Re-running the generator after a page disappears, and running it from `website/` as cwd** (the npm `prebuild`). Expected: the owned output directories are cleared first, so no stale page survives, and every path resolves from the repo root, not from cwd. Pinned by `DocsGenRunTests.Owned_outputs_are_cleared_before_writing` and `DocsGenPathsTests.Resolves_from_any_working_directory` (Task 5).
5. **XML-doc lookups that miss silently** (doc-comment IDs for generic, nullable, `params`, by-ref and extension-method parameters). Expected: every in-scope public member of a shipped package renders a non-empty summary, because XML docs are mandatory on public API. Pinned by `CSharpApiTests.Every_in_scope_member_has_a_summary` and `DocIdTests` (Tasks 6 and 10).
6. **A captured exchange that leaks or lies.** Expected: the real secret never reaches generated output (it is rendered as `<keyId>.$<VARIABLE>`), a step whose real status differs from `expect` fails the build instead of rendering, and a placeholder that resolves to nothing throws. Pinned by `ExchangeRendererTests.The_secret_never_reaches_the_output`, `ExchangeRunnerTests.A_wrong_expectation_fails_the_run` and `PlaceholdersTests` (Task 8).
7. **Phone width and keyboard.** Expected: no horizontal page scroll at 390px on the landing page and a guide, in both themes; every header/footer control is ≥ 44px; a focused link shows an outline. Pinned by `npm run check:ux` (Task 4, extended in Task 9).

export function remarkMermaidPre() {
  return (tree) => {
    visit(tree, 'code', (node, index, parent) => {

    });
  };
}

```astro

import { Code } from '@astrojs/starlight/components';
interface Props { code: string; from: string; to: string; lang?: string; title?: string }
const { code, from, to, lang = 'csharp', title } = Astro.props;
const lines = code.replace(/\r\n/g, '\n').split('\n');
const start = lines.findIndex((line) => line.includes(from));
const end = start < 0 ? -1 : lines.findIndex((line, i) => i >= start && line.includes(to));
if (start < 0 || end < 0) throw new Error(`SourceExcerpt: anchors not found (from "${from}", to "${to}")`);
const slice = lines.slice(start, end + 1);
const indent = Math.min(...slice.filter((l) => l.trim()).map((l) => l.match(/^ */)[0].length));
const excerpt = slice.map((l) => l.slice(indent)).join('\n');
---
<Code code={excerpt} lang={lang} title={title} />
```

const start = css.indexOf(opener);
if (start < 0) throw new Error(`sync-tokens: no "${opener}" block in ${source.pathname}`);
const bodyStart = start + opener.length;

function closingBrace(text, from) {
  let depth = 1;

    if (text[i] === '{') depth++;

using System.Globalization;
using System.Text;
using System.Text.RegularExpressions;

namespace MMLib.Alvo.DocsGen.Markdown;

internal static partial class Md
{
    internal static string Text(string value)
    {
        var collapsed = Whitespace().Replace(value, " ");
        var builder = new StringBuilder(collapsed.Length);
        foreach (var character in collapsed)
        {
            builder.Append(Escape(character));
        }

        return builder.ToString();
    }

    internal static string Cell(string value) => Text(value).Replace("|", @"\|", StringComparison.Ordinal);

    internal static string Code(string value)
    {
        var collapsed = Whitespace().Replace(value, " ");
        return collapsed.Contains('`', StringComparison.Ordinal) ? $"`` {collapsed} ``" : $"`{collapsed}`";
    }

    internal static string CodeCell(string value) => Code(value).Replace("|", @"\|", StringComparison.Ordinal);

    internal static string Anchor(string id) => $"<a id=\"{id}\"></a>";

    internal static string Yaml(string value) =>
        "\"" + value.Replace(@"\", @"\\", StringComparison.Ordinal).Replace("\"", "\\\"", StringComparison.Ordinal) + "\"";

    internal static string Frontmatter(string title, string description, int? order = null, string? sidebarLabel = null, int? tocMaxHeadingLevel = null)
    {
        var builder = new StringBuilder("---\n")
            .Append("title: ").Append(Yaml(title)).Append('\n')
            .Append("description: ").Append(Yaml(Whitespace().Replace(description, " ").Trim())).Append('\n');
        AppendSidebar(builder, order, sidebarLabel);
        if (tocMaxHeadingLevel is { } level)
        {
            builder.Append("tableOfContents:\n  maxHeadingLevel: ").Append(level.ToString(CultureInfo.InvariantCulture)).Append('\n');
        }

        return builder.Append("---\n\n").ToString();
    }

    private static void AppendSidebar(StringBuilder builder, int? order, string? label)
    {
        if (order is null && label is null)
        {
            return;
        }

        builder.Append("sidebar:\n");
        if (order is { } position)
        {
            builder.Append("  order: ").Append(position.ToString(CultureInfo.InvariantCulture)).Append('\n');
        }

        if (label is not null)
        {
            builder.Append("  label: ").Append(Yaml(label)).Append('\n');
        }
    }

    private static string Escape(char character) => character switch
    {
        '<' => "&lt;",
        '>' => "&gt;",
        '*' => @"\*",
        '_' => @"\_",
        _ => character.ToString(),
    };

    [GeneratedRegex(@"\s+")]
    private static partial Regex Whitespace();
}

namespace MMLib.Alvo.DocsGen;

internal sealed record DocsGenPaths(string RepoRoot, string SiteRoot, string ReferenceDir)
{
    private const string SolutionFileName = "MMLib.Alvo.slnx";

    internal string DocsDir => Path.Combine(SiteRoot, "src", "content", "docs");
    internal string GeneratedDir => Path.Combine(SiteRoot, "src", "generated");
    internal string PublicDir => Path.Combine(SiteRoot, "public");

    internal IReadOnlyList<string> OwnedDirectories => [ReferenceDir, GeneratedDir];

    internal IReadOnlyList<string> OwnedFiles =>
    [
        Path.Combine(DocsDir, "project", "changelog.md"),
        Path.Combine(DocsDir, "project", "contributing.md"),
        Path.Combine(PublicDir, "llms.txt"),
        Path.Combine(PublicDir, "llms-full.txt"),
    ];

    internal string RootOf(OutputRoot root) => root switch
    {
        OutputRoot.Reference => ReferenceDir,
        OutputRoot.Docs => DocsDir,
        OutputRoot.Generated => GeneratedDir,
        OutputRoot.Public => PublicDir,
        _ => throw new ArgumentOutOfRangeException(nameof(root), root, null),
    };

    internal static DocsGenPaths Parse(IReadOnlyList<string> args, string workingDirectory, string startDirectory)
    {
        var options = ReadOptions(args);
        var repo = Resolve(workingDirectory, options.GetValueOrDefault("--repo")) ?? FindRepository(startDirectory);
        var site = Resolve(workingDirectory, options.GetValueOrDefault("--site")) ?? Path.Combine(repo, "website");
        var reference = Resolve(workingDirectory, options.GetValueOrDefault("--out"))
            ?? Path.Combine(site, "src", "content", "docs", "reference");
        return new DocsGenPaths(repo, site, reference);
    }

    private static Dictionary<string, string> ReadOptions(IReadOnlyList<string> args)
    {
        string[] known = ["--repo", "--site", "--out"];
        var options = new Dictionary<string, string>(StringComparer.Ordinal);
        for (var i = 0; i < args.Count; i += 2)
        {
            if (!known.Contains(args[i], StringComparer.Ordinal) || i + 1 >= args.Count)
            {
                throw new ArgumentException($"Unknown or incomplete argument '{args[i]}'. Use --repo, --site or --out <path>.", nameof(args));
            }

            options[args[i]] = args[i + 1];
        }

        return options;
    }

    private static string? Resolve(string workingDirectory, string? value) =>
        value is null ? null : Path.GetFullPath(Path.Combine(workingDirectory, value));

    private static string FindRepository(string startDirectory)
    {
        for (var directory = new DirectoryInfo(startDirectory); directory is not null; directory = directory.Parent)
        {
            if (File.Exists(Path.Combine(directory.FullName, SolutionFileName)))
            {
                return directory.FullName;
            }
        }

        throw new InvalidOperationException($"No {SolutionFileName} above '{startDirectory}'; pass --repo <path>.");
    }
}

using MMLib.Alvo.DocsGen.Schema;

namespace MMLib.Alvo.DocsGen;

internal static class DocsGenRun
{
    internal static IReadOnlyList<IPageGenerator> Generators { get; } = [new SchemaPagesGenerator()];

    internal static async Task<int> RunAsync(DocsGenPaths paths, IReadOnlyList<IPageGenerator> generators, CancellationToken ct)
    {
        ClearOwnedOutputs(paths);
        var context = new DocsGenContext(paths);
        foreach (var generator in generators)
        {
            var pages = await generator.GenerateAsync(context, ct).ConfigureAwait(false);
            await WriteAsync(paths, pages, ct).ConfigureAwait(false);
        }

        return 0;
    }

    private static void ClearOwnedOutputs(DocsGenPaths paths)
    {
        foreach (var directory in paths.OwnedDirectories.Where(Directory.Exists))
        {
            Directory.Delete(directory, recursive: true);
        }

        foreach (var file in paths.OwnedFiles.Where(File.Exists))
        {
            File.Delete(file);
        }
    }

    private static async Task WriteAsync(DocsGenPaths paths, IReadOnlyList<GeneratedPage> pages, CancellationToken ct)
    {
        foreach (var page in pages)
        {
            var target = Path.Combine(paths.RootOf(page.Root), page.RelativePath);
            Directory.CreateDirectory(Path.GetDirectoryName(target)!);
            await File.WriteAllTextAsync(target, page.Content, ct).ConfigureAwait(false);
        }
    }
}

```csharp
namespace MMLib.Alvo.DocsGen.Schema;

internal sealed record SchemaKey(
    string Path,
    string Anchor,
    string Type,
    bool Required,
    string Description,
    IReadOnlyList<string> Values,
    string? Default,
    string? Pattern,
    IReadOnlyList<string> Notes);
```
The walker's rules (implement as small named methods, ≤ ~25 lines each):
- **Resolve(node)**: follow `$ref` (`#/$defs/<name>`) repeatedly. The description is the first non-empty `description` along the chain, starting at the referring node (an own `description` beside a `$ref` wins).
- **Key emission**: `AddKey(path, anchor, IReadOnlyList<JsonObject> schemas, bool required, List<string> inheritedNotes)`. A key may be described by several schemas (merged `oneOf` variants). Type is the union of each schema's type label, joined with ` or `. Values is the union of `enum` items and `const` values (`ToJsonString()`). Description is the first non-empty. Default and Pattern come from the first schema that has one.
- **Type label**: `type` string or array (`string or object`). If there is none: from `const`'s JSON kind, `enum` → `string` when every item is a string, `oneOf`/`anyOf` → union of branch labels, else `any`. `object` whose only children come from `additionalProperties` → `map of <label>`; `array` → `array of <items label>`.
- **Expanded refs**: before recursing into a `$ref` whose target has `properties`, `additionalProperties` (object), `items` or object-typed `oneOf` branches, check `_expanded[defName]`. When it is already set, add the note ``Same shape as [`<first path>`](#<first anchor>).`` and do not recurse. Otherwise record `(path, anchor)`. `_expanded` is reset per `KeysOf` call (one page).
- **Children of an object**: `properties` (a boolean `false` value → parent note ``Reserved name: `<name>` is not allowed.``; when inside `then`, it is never visited as a child). `additionalProperties` object → parent note ``Each entry: <entry description>`` and recursion with path `<path>.<name>` and the same anchor. `propertyNames.pattern` → parent note ``Names match `<pattern>`.``. `items` object → recursion with path `<path>[]` and the same anchor. `oneOf`/`anyOf` object branches → collect each branch's `properties` by name, then `AddKey` once per name with all of that name's schemas.
- **Anchors**: child anchor = parent anchor + `.` + property name. `<name>` and `[]` never appear.
- **Required**: the parent's `required` contains the name (for merged variants: required in every variant that declares it).
- **Conditions** (`allOf` items and a direct `if`/`then` on the object), recognised shapes only:
  - `if.properties.X.const == V` and `then.required` contains K → K note ``Required when `X` is `<V json>`.``
  - `if.not.properties.X.const == V` and `then.properties.K == false` → K note ``Allowed only when `X` is `<V json>`.``
  - `if.required == [A]` and `then.properties.K == false` → K note ``Not allowed together with `A`.``
  - anything else → `_unrecognised.Add($"{path}: {conditionJson}")`.
- **Top level**: `TopLevelKeys` follows `properties` order. `IsBlock(key)` holds when the resolved schema has `properties`, an object `additionalProperties`, or object-typed `oneOf`. `patternProperties` on the root → the index page note ``Keys matching `<pattern>` are accepted.``.

```csharp
using System.Reflection;

namespace MMLib.Alvo.DocsGen.Xml;

internal static class DocId
{
    internal static string Of(Type type) => "T:" + TypeName(type);

    internal static string Of(FieldInfo field) => $"F:{TypeName(field.DeclaringType!)}.{field.Name}";

    internal static string Of(PropertyInfo property)
    {
        var indexers = property.GetIndexParameters();
        var parameters = indexers.Length == 0 ? string.Empty : $"({string.Join(',', indexers.Select(p => ParameterType(p.ParameterType)))})";
        return $"P:{TypeName(property.DeclaringType!)}.{property.Name}{parameters}";
    }

    internal static string Of(MethodBase method)
    {
        var name = method is ConstructorInfo ? "#ctor" : method.Name;
        var arity = method.IsGenericMethod ? "``" + method.GetGenericArguments().Length.ToString(System.Globalization.CultureInfo.InvariantCulture) : string.Empty;
        var parameters = method.GetParameters();
        var list = parameters.Length == 0 ? string.Empty : $"({string.Join(',', parameters.Select(p => ParameterType(p.ParameterType)))})";
        return $"M:{TypeName(method.DeclaringType!)}.{name}{arity}{list}";
    }

    private static string TypeName(Type type) => (type.FullName ?? $"{type.Namespace}.{type.Name}").Replace('+', '.');

    private static string ParameterType(Type type)
    {
        if (type.IsByRef) return ParameterType(type.GetElementType()!) + "@";
        if (type.IsArray) return ParameterType(type.GetElementType()!) + "[]";
        if (type.IsGenericMethodParameter) return "``" + type.GenericParameterPosition.ToString(System.Globalization.CultureInfo.InvariantCulture);
        if (type.IsGenericTypeParameter) return "`" + type.GenericParameterPosition.ToString(System.Globalization.CultureInfo.InvariantCulture);
        return type.IsGenericType ? GenericInstance(type) : TypeName(type);
    }

    private static string GenericInstance(Type type)
    {
        var definition = TypeName(type.GetGenericTypeDefinition());
        var bare = definition[..definition.IndexOf('`', StringComparison.Ordinal)];
        return $"{bare}{{{string.Join(',', type.GetGenericArguments().Select(ParameterType))}}}";
    }
}
```

### Content tasks (12–16): shared rules

These apply to every page in Tasks 12–16. The plan cannot contain finished prose. Per page it gives the goal, the sources to read (read them; do not write from the brief alone), the required sections, the snippets and exchange specs to create, the problem types to list, and the not-shipped items to flag.

- **The guide template (`D-S12`, spec §4.2)** — every guide has, in order:
  1. frontmatter `title` (a noun people search for) and `description` (the lede, phrased as a task);
  2. a `:::tip[What you will achieve]` aside: the outcome, the time it takes, the starting point;
  3. `## Before you start`: one to three bullets — the stack (link `/MMLib.Alvo/start-here/run-your-own/`), the key and roles the page uses, any prior guide;
  4. one `##` per step: the descriptor change (an imported snippet with the new lines marked by Expressive Code `ins={…}` ranges), how to apply it (link `/MMLib.Alvo/guides/apply-and-evolve/` the first time), then `<Exchange name="…" />` — request and real response inline, never in tabs;
  5. optional `## How it works`: at most one paragraph, linking the concept page;
  6. optional `## Options and variations`: a table whose cells link reference anchors (`/MMLib.Alvo/reference/descriptor/entities-fields/#entities.fields.maxLength`);
  7. optional `:::caution[Not in this build]`: what is missing, linking `/MMLib.Alvo/reference/capabilities/` and the tracking issue when the source names one;
  8. `## What can go wrong`: a table `| Status | Problem type | When | Fix | Returned by |`, the slug linking `/MMLib.Alvo/reference/problem-types/#<slug>`, "Returned by" saying *every host*, or *standalone; embedded only with `AddAlvoProblemDetails()`* for `function-failed`, `internal`, `unreadable-request` (`D-S11`). List only slugs the cited code path really emits; confirm each against `docs/architecture/data-api.md` § "The status and `type`-slug catalogue" or the section cited;
  9. `## Reference`: the keys, functions and problem types the page uses, as links;
  10. `## Next`: one recommended page.
  Tutorials drop 5 and 6 and end with `## What you built`. Concept pages drop 3, 4 and 8 and end with `## Put it to work`.
- **Snippets:** `website/src/snippets/<page-slug>/<nn>-<what>.alvo.json`, full descriptors, imported with `import x from '../../../snippets/…?raw'` and shown with `<Code code={x} lang="json" title="…" ins={…} />`, or a subtree with `<JsonExcerpt code={x} pointer="/entities/…" />`. A snippet that shows a feature this build refuses goes in a sibling directory with a `NOT-RUNNABLE.md` that says why; `DocsSnippetTests` enforces that the marker is true.
- **Exchanges:** `website/src/exchanges/<page-slug>/<nn>-<what>.exchange.json` (Task 8 shape), one per step that shows HTTP. Keys are named for their role (`agent`, `admin`, `reader`), and each key's `secretVariable` matches the variable the page's *Before you start* tells the reader to export. Set `expect` (and `expectType` for a refusal) from the source document first; when the real host disagrees, the build fails, and you investigate: fix the request if it was wrong, or report a product/doc mismatch in the commit body. Never set `expect` to whatever came back without understanding why.
- **Shell blocks:** files under `website/src/snippets/shell/`, imported with `?raw`; the task's verification runs each one (or `docker compose … config` for a compose file).
- **Links:** architecture notes are linked as GitHub blob URLs. Product docs (Slovak) are never linked from the site (spec §6.3). Every guide links *Run your own descriptor* in *Before you start*.
- **Mockup facts are not facts (`D-M6`):** `reject` is a string; a mutate facet break is a 403 `forbidden` (data-api.md Ruling V), not a 422; a bare `docker compose up --wait` fails (the `:?` secret guard); every curl carries `X-Alvo-Api-Key` and, with a body, `Content-Type: application/json`; no hard-coded function count (link the CEL catalog); dynamic entities are "planned".
- **Per-task verification:** `cd website && npm run build` (links validated, exchanges captured, every `expect` met) and `scripts/test-ring0` (snippets, exchange specs). Add the task's key pages to `ux-check.mjs`'s page list and run `npm run check:ux && npm run check:a11y`. Then `grep -rl 'STUB-F6' website/src/content/docs` lists only pages later tasks write.
