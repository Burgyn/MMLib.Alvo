# HX-16 — Enricher, narrowing, virtual fields — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Host C# may shape what a read returns, and nothing more: a *narrowing* ANDs a host filter into the compiled SQL of list, get and count for every non-system caller, and an *enricher* may only remove a field from a returned row or fill a field the descriptor declares `"virtual": true` — a field with no column that is read-only everywhere and refused in writes, in every CEL slot and in `filter`/`sort`/`select`.

**Architecture:** One internal driver port, `IReadExtensionRunner` (Abstractions `MMLib.Alvo.Rules`, reached by the EF driver through Abstractions' existing `InternalsVisibleTo`), implemented in the core over the extension registry and binder HX-03…HX-09 built. The driver asks it once per read for a `ReadNarrowing` (an `AlvoFilter` plus the ids it came from), which `ReadStatementComposer` renders as its own parenthesised `WHERE` term under its own bind-parameter family (`alvo_n`) — after `USING` and the tenant scope, beside the caller's filter, never inside it — so the page, its keyset anchor and its count share it. For enrichment the driver opens one `IReadEnrichment` per read and passes every materialized row (page, get, write echo, replay) through it after the policy mask. A virtual field is a `FieldSchema` with `IsVirtual`: the EF model maps no column for it, the projection never selects it, the driver pre-fills it with `null` on a row that may carry it, and every write and query guard refuses it.

**Tech Stack:** .NET 10 (C# 14), EF Core 10 (SQLite, Npgsql — PostgreSQL 16 in Testcontainers), xUnit v3 on Microsoft.Testing.Platform, Shouldly, Verify + PublicApiGenerator, CsCheck, Blazor (dashboard), Microsoft.Playwright (admin e2e), Astro/Starlight (docs).

**Spec:** `docs/superpowers/specs/2026-10-14-host-extensibility-design.md` — §4.12 (the whole mechanism), §1.1 goal 5, §1.2 (no row rewriting after SQL), §4.4.5 (the boot ban the enricher inherits), §4.3 query column (narrowing → `AlvoFilter`) and *HX-05 settled details* (9), (10), (13), (25), §4.13 (catalog kinds `Enricher`/`Narrowing`, stage `Read`, the *Reads* lane), *HX-04 settled details* (1), (17) (append-only enums), §5 row `16`, §6.2 row *reads*, §7 *HX-16*. **Prior art.** PostgreSQL RLS: a `RESTRICTIVE` policy is ANDed with the permissive ones and can only remove rows — a narrowing is exactly that, authored in C#; deviation: RLS applies a restrictive `USING` to `UPDATE`/`DELETE` too, a narrowing does not (§4.12 "writes are not narrowed"). ## Decisions (not settled by the spec)

Recorded in the spec as *HX-16 settled details* (Task 11). Format: decision — cost if wrong.

1. **A driver port, not an `IAlvoData` decorator**: a decorator cannot AND into `get` (it would turn a get into a list under the other rule), would push the narrowing through the caller-filter limits and hidden-field guard, and units bypass decorators. `InMemoryAlvoData` runs no read extension (documented, as it runs no unit — HX-07) but refuses a write naming a virtual field like the driver. — Cost: an in-memory test sees no narrowing or enrichment.
2. **System = `context.ActorKind == AlvoActorKind.System`** (the `AlvoTransactionOptions` precedent); every other caller is narrowed, inside a unit too. — Cost: a host passing a hand-built system context skips its own narrowing, by design.
3. **Write echoes and idempotent replays are read back under the `get` decision *and* the narrowing (operation `Get`), then enriched with the write's operation**; a narrowed-out echo answers the id alone, as a `get`-excluded one does. Only the write's target rows and pre-images are not narrowed ("writes are not narrowed"). A narrowing is a **view, not an authorization boundary** — the docs and the spec say "use rules" for what a caller must not touch. — Cost: one narrowing call per write echo.
4. **Fail closed**: a registered narrowing or enricher that is unbound for the current catalog, throws, is untranslatable, exceeds `AlvoFilter` limits or names a missing or virtual field fails the read with 500 `hook-failed`. — Cost: a defective extension takes its entity's reads down instead of leaking rows.
5. **A narrowing may name a field the policy hides from the caller**, as a rule's `USING` may (host-authored, not caller-controlled); the runner logs `NarrowingNamesHiddenField` (Warning, ids only) once per extension and field — at first use, since the filter exists only at run time. — Cost: the predicate is observable through which rows survive; refusing later is one check in `ReadExtensionRunner.Checked`.
6. **The enricher sees the masked row only**; `SetVirtual` on a virtual field the row does not carry (hidden from this caller, or not selected) is a no-op, so an enricher can never resurrect a hidden field. — Cost: no virtual value derived from data the caller cannot read.
7. **`Hide` refuses framework columns** (`AlvoManagedColumns.For(entity)`: `id`, `tenant_id`, audit, version, `deleted_at`) — `invalid-hide`. — Cost: none known; keeps ETags and cursors intact.
8. **A virtual field the caller may read and selected is always present, `null` until an enricher fills it** — a stable key set, and `As<T>()` keeps working. — Cost: payload bytes.
9. **`virtual` is refused with** `computed`, `rollup`, `default`, `required`, `unique`, `index`, `validation`, `renamedFrom`, type `ref`, in `indexes[].fields`, as a rollup's `field`/`via`, in `events.exclude`, and on a dynamic entity. — Cost: each relaxes later additively.
10. **Untyped path:** the enricher is `IRecordEnricher<AlvoRecord>` (no new type); the narrowing is a new `IQueryNarrowing` returning `AlvoFilter?` (X7: untyped = `AlvoFilter`). Delegate forms are `Func<>`/`Action<>` without DI parameters (HX-09's `Delegate` forms resolve DI). — Cost: DI in delegates is an additive overload later.
11. **No options type; order = registration order; `"*"` refused at boot.** Catalog: a narrowing lists operations `list`, `get`; an enricher `list`, `get`, `create`, `update`; `When` is `null` (deviation from §4.13 "narrowing shows its filter" — the filter is per caller). — Cost: a follow-up to render it in the simulator.
12. **The §4.4.5 boot ban covers the narrowing too** (§4.12 names the enricher; both run in the same read, possibly inside a unit). — Cost: a narrowing cannot look up memberships through `IAlvoData`; it reads them from the caller or a cache.
13. **Port refusal families:** a virtual field in a write payload is `AlvoAuthorizationException` (the computed/rollup precedent; the Data API answers 422 first through `RecordValidator`); in a port filter/sort/select it is the undeclared-field refusal (indistinguishable from hidden); the Data API answers 422 `virtual-field` for one the caller can read. — Cost: an embedded caller sees 403 where HTTP sees 422.
14. **No telemetry span per read** (failures logged with ids only; `Hooks.AssertRan` counts no read), and **class extensions come from one `CreateAsyncScope()` per read**, opened only when a class extension is registered on the entity. — Cost: no p95 in the *Reads* lane; a scope per read on such entities.
15. **The Data API's reference probe (`RecordValidator.IsResolvableAsync`) reads under rules only** — neither narrowing nor enrichment — inside an internal `AlvoFlow.EnterRulesOnlyRead()` scope the runner honours, so the 422 for an unresolvable `ref` matches the port, which checks references under rules alone. — Cost: a caller can reference a row its narrowing hides (the view is not a boundary, Decision 3).

```csharp
/// <summary>Narrows what a non-system caller reads of one entity: the filter is ANDed into the SQL of list, get and count.</summary>
public interface IQueryNarrowing<T> where T : class
{
    /// <summary>The rows this caller may see at most, or <see langword="null"/> to leave the read as the rules made it.</summary>
    /// <param name="narrowing">The read being narrowed.</param>
    /// <returns>A predicate translated to an <see cref="AlvoFilter"/> per call, or <see langword="null"/>.</returns>
    Expression<Func<T, bool>>? Narrow(QueryNarrowing narrowing);
}

/// <summary>The untyped narrowing: an <see cref="AlvoFilter"/> ANDed into the SQL of list, get and count.</summary>
public interface IQueryNarrowing
{
    /// <summary>The rows this caller may see at most, or <see langword="null"/>.</summary>
    /// <param name="narrowing">The read being narrowed.</param>
    /// <returns>The filter ANDed into the read, or <see langword="null"/>.</returns>
```

```csharp
internal sealed partial class ReadExtensionRunner(
    ExtensionRegistry registry, ExtensionBinder binder, IPolicyCatalogProvider catalogs, IServiceScopeFactory scopes,
    ILogger<ReadExtensionRunner> logger) : IReadExtensionRunner
{
    public ReadNarrowing? Narrowing(string entity, DataOperation operation, AlvoContext context)
    {
        var registered = registry.ReadExtensions.Where(read => read.Kind == ReadExtensionKind.Narrowing && read.Covers(entity)).ToList();
        if (registered.Count == 0 || context.ActorKind == AlvoActorKind.System)
        {
            return null;
        }

        if (AlvoFlow.IsRulesOnlyRead)
        {
            return null;
        }

        var (schema, bindings) = Bound(entity);
        using var scope = registered.Any(read => read.Invoker.IsClass) ? scopes.CreateAsyncScope() : (AsyncServiceScope?)null;
        var services = scope?.ServiceProvider ?? EmptyServices.Instance;
        var query = new QueryNarrowing(context, entity, operation);
        var terms = registered
            .Select(narrowing => Narrowed(narrowing, bindings, schema, services, query))
            .OfType<AlvoFilter>()
            .ToList();

        return terms.Count == 0 ? null : new ReadNarrowing(terms.Count == 1 ? terms[0] : new AlvoAnd(terms), [.. registered.Select(read => read.Id)]);
    }

    private (EntitySchema? Schema, ExtensionBindings Bindings) Bound(string entity)
    {
        var catalog = catalogs.Current;
        return catalog is null
            ? (null, ExtensionBindings.None)
            : (catalog.Schema.Entities.FirstOrDefault(candidate => candidate.Name == entity), binder.For(catalog));
    }

    private AlvoFilter? Narrowed(
        ReadExtensionRegistration narrowing, ExtensionBindings bindings, EntitySchema? schema, IServiceProvider services, QueryNarrowing query)
    {
        if (schema is null || bindings.ReadExtension(narrowing.Id) is null)
        {
            throw Failed(narrowing.Id, HookFailedException.Unbound, cause: null);
        }

        AlvoFilter? filter;
        try
        {
            filter = narrowing.Invoker.Narrow!(services, query);
        }
        catch (Exception cause) when (cause is not OperationCanceledException)
        {
            throw Failed(narrowing.Id, cause is AlvoTranslationException ? HookFailedException.Translation : HookFailedException.Exception, cause);
        }

        return filter is null ? null : Checked(narrowing.Id, filter, schema);
    }

    private AlvoFilter Checked(string id, AlvoFilter filter, EntitySchema schema)
    {
        try
        {
            AlvoFilter.EnsureWithinLimits(filter);
        }
        catch (ArgumentException cause)
        {
            throw Failed(id, HookFailedException.InvalidFilter, cause);
        }

        return AlvoFilter.ReferencedFields(filter).All(name => Filterable(name, schema))
            ? filter
            : throw Failed(id, HookFailedException.InvalidFilter, cause: null);
    }

    private static bool Filterable(string name, EntitySchema schema) =>
        AlvoManagedColumns.For(schema).Contains(name) || schema.Fields.Any(field => field.Name == name);

    private HookFailedException Failed(string id, string reason, Exception? cause)
    {
        ReadExtensionFailed(logger, cause, id, reason);
        var failure = HookFailedException.OfRead([id], reason);
        AlvoFlow.Unit?.Blame(failure);
        return failure;
    }

    [LoggerMessage(EventId = 7301, Level = LogLevel.Error, Message = "Read extension {Extension} failed ({Reason}).")]
    private static partial void ReadExtensionFailed(ILogger logger, Exception? exception, string extension, string reason);
}
```

```csharp
/// <summary>A materialized row as the caller receives it: masked, unselected fields absent, every virtual field it may carry present.</summary>
private static AlvoRecord Shaped(
    Dictionary<string, object> row, EntitySchema? schema, IReadOnlySet<string> hidden, IReadOnlySet<string> unselected)
{
```

```csharp
/// <summary>Shapes each row a read returns: it may only hide a field or fill a field the descriptor declares virtual.</summary>
public interface IRecordEnricher<T> where T : class
{
    /// <summary>Shapes one returned row, synchronously, after the caller's rules and masks.</summary>
    /// <param name="row">The row and the two moves allowed on it.</param>
    void Enrich(Enrich<T> row);
}

/// <summary>One returned row an enricher may shape: hide a field, or fill a virtual one. Nothing else.</summary>
/// <typeparam name="T">The row's type: a mapped class, or <see cref="AlvoRecord"/>.</typeparam>
public sealed class Enrich<T> where T : class
{
    private readonly RowShaping _row;

    internal Enrich(RowShaping row, AlvoContext caller, DataOperation operation) { _row = row; Caller = caller; Operation = operation; Row = row.As<T>(); }

    /// <summary>Gets the row as the caller receives it so far — a field the caller may not read is absent (a typed property reads its default).</summary>
    public T Row { get; }

    /// <summary>Gets the caller the row is returned to; the system too, which is enriched like any caller.</summary>
    public AlvoContext Caller { get; }

    /// <summary>Gets <see cref="DataOperation.Get"/>, <see cref="DataOperation.List"/>, or <see cref="DataOperation.Create"/>/<see cref="DataOperation.Update"/> for a write's echo.</summary>
    public DataOperation Operation { get; }

    /// <summary>Gets the entity the row belongs to.</summary>
    public string Entity => _row.Entity;

    /// <summary>Removes a field from this row. A framework column cannot be hidden.</summary>
    /// <param name="field">The field's name.</param>
    public void Hide(string field) => _row.Hide(field);

    /// <summary>Removes the field a mapped property names from this row. A framework column cannot be hidden.</summary>
    /// <typeparam name="TValue">The property's type.</typeparam>
    /// <param name="field">The property, such as <c>x =&gt; x.Region</c>.</param>
    public void Hide<TValue>(Expression<Func<T, TValue>> field) => _row.Hide(TypedField.Of(field));

    /// <summary>Fills a field the descriptor declares virtual; a no-op when this row does not carry it (hidden from the caller, or not selected).</summary>
    /// <param name="field">The virtual field's name.</param>
    /// <param name="value">A value its type holds, or <see langword="null"/>.</param>
```

```csharp
internal sealed class RowShaping(EntitySchema schema, AlvoRecord row, FormatCatalog formats)
{
    private readonly Dictionary<string, object?> _values = new(row.Values, StringComparer.Ordinal);
    private readonly IReadOnlySet<string> _framework = AlvoManagedColumns.For(schema);

    internal string Entity => schema.Name;

    internal T As<T>() where T : class => typeof(T) == typeof(AlvoRecord)
        ? (T)(object)ToRecord()
        : RecordShape.Of(typeof(T)).Materialize<T>(ToRecord(), static _ => true);

    internal void Hide(string field)
    {
        if (_framework.Contains(field))
        {
            throw new ReadShapingRefusal(HookFailedException.InvalidHide);
        }

        _values.Remove(field);
    }

    internal void SetVirtual(string field, object? value)
    {
        var declared = schema.Fields.FirstOrDefault(candidate => candidate.Name == field);
        if (declared is not { IsVirtual: true } || !Holds(declared, value))
        {
            throw new ReadShapingRefusal(HookFailedException.InvalidSet);
        }

        if (_values.ContainsKey(field))
        {
            _values[field] = value;
        }
    }

    internal AlvoRecord ToRecord() => new(_values);

    private bool Holds(FieldSchema field, object? value) =>
        value is null
        || (FieldClrType.Of(field).IsInstanceOfType(value) && new MutationTarget(field, formats, Disclosable: true).Violation(value) is null);
}

internal sealed class ReadShapingRefusal(string reason) : Exception(reason) { internal string Reason { get; } = reason; }
```
