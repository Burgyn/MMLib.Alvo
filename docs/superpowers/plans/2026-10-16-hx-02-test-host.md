# HX-02 — `MMLib.Alvo.TestHost` and the docs-snippet harness — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `MMLib.Alvo.TestHost` — a real Alvo backend inside a unit test (production pipeline over a private in-memory SQLite database, event delivery on the test's schedule, a hook recorder and loop detection) — plus the core's manual dispatch mode it stands on, and `test/MMLib.Alvo.DocsSnippets.Tests`, which compiles and runs every C# snippet under `website/src/snippets/extending/**`.

**Architecture:** The core gains `AlvoEventOptions.DispatchMode` (`Background` default, `Manual`; the standalone host refuses `Manual`) and a public, dispatcher-neutral `IAlvoEventPump` whose one internal implementation (`EventPump`) runs a round of every dispatcher — in this build only the existing `OutboxDispatcher`: in manual mode its background loop logs a stand-down line and never claims, and each `DrainAsync()` runs exactly one tick of that loop (claim, after-hooks, retire/release) and reports it as an `AlvoDrainResult`. Every descriptor after-hook action becomes one `alvo.delivery` activity on the `MMLib.Alvo.Hooks` `ActivitySource` (spec §4.14). The new package composes an empty generic host with `AddAlvo(configure)`, an in-memory SQLite database unless `configure` registered a provider, `Alvo:Events:DispatchMode = Manual`, an optional `TimeProvider`, and a webhook primary handler that is the test's stub or a refusing handler; `DrainEventsAsync` loops `DrainAsync` until quiet (≤ 100 rounds), and `AlvoHookRecorder` reads the activity source, scoped to its own host's drains by trace id. The snippet harness is a test project that compiles the snippet files as ordinary sources.

**Tech Stack:** .NET 10, C#, xUnit v3 on Microsoft.Testing.Platform, Shouldly, Verify + PublicApiGenerator, NetArchTest, Testcontainers (PostgreSQL), Microsoft.Extensions.Hosting / Http / Configuration (via the `Microsoft.AspNetCore.App` framework reference), `Microsoft.Extensions.TimeProvider.Testing` 10.10.0, `System.Diagnostics.ActivitySource`, Astro/Starlight (docs).

**Spec:** `docs/superpowers/specs/2026-10-14-host-extensibility-design.md` — §4.15 (Testing kit), §4.14 (Observability, the activity source), §5 rows marked `02`, §7 *HX-02* (scope + acceptance (1)–(6)), the §7 preamble (docs/snippets/dashboard per PR), §2.2 C1 and C8, §2.3 X11, Appendix A R-12 and minor 23. namespace MMLib.Alvo.Events;

```csharp
/// <summary>
/// Runs one round of every event dispatcher Alvo runs, on the caller's schedule, when
/// <see cref="AlvoEventOptions.DispatchMode"/> is <see cref="AlvoEventDispatchMode.Manual"/>.
/// </summary>
/// <remarks>
/// <para>
/// A round is what the background dispatchers do on one tick each: claim the work that is due, run it, retire what
/// succeeded and hand back what failed under the usual backoff. Nothing is skipped or shortened, so a caller driving the
/// pump sees what production delivers. Work a round causes — an event a delivery writes — is due in the next round.
/// </para>
/// <para>
/// <b>Refused unless the dispatchers are manual.</b> Two drivers of one queue break per-entity-key ordering the way two
/// dispatching replicas do, so in the background mode a round throws instead of racing the loops. Rounds called
/// concurrently run one after the other; a round called from inside a round would wait for itself, so a subscriber
/// must never drain.
/// </para>
/// </remarks>
public interface IAlvoEventPump
{
    /// <summary>Runs one dispatch round.</summary>
    /// <param name="cancellationToken">
    /// Cancels the round; work in flight is left claimed, and its lease returns it to the queue.
    /// </param>
    /// <returns>What the round claimed, which subscribers it ran and how many attempts failed.</returns>
    /// <exception cref="InvalidOperationException">
    /// The dispatch mode is not <see cref="AlvoEventDispatchMode.Manual"/>, <see cref="AlvoEventOptions.Enabled"/> is
    /// off, or the boot has not primed a schema; nothing was claimed.
    /// </exception>
    Task<AlvoDrainResult> DrainAsync(CancellationToken cancellationToken = default);
}
```

```csharp
namespace MMLib.Alvo.Events.Internal;

/// <summary>The tally one dispatch round keeps while it runs: which subscribers ran, and how many attempts failed.</summary>
internal sealed class DrainRound
{
    private readonly List<string> _subscribers = [];
    private readonly HashSet<string> _seen = new(StringComparer.Ordinal);
    private int _failed;

    /// <summary>Records that <paramref name="subscriber"/> ran, keeping first-run order and naming it once.</summary>
    internal void Ran(string subscriber)
    {
        if (_seen.Add(subscriber))
        {
            _subscribers.Add(subscriber);
        }
    }

    /// <summary>Records one failed attempt.</summary>
    internal void Failed() => _failed++;

    /// <summary>The round's result once every claimed entry has been dispatched.</summary>
    internal AlvoDrainResult Result(int claimed) => new()
    {
        Claimed = claimed,
        Failed = _failed,
        Subscribers = [.. _subscribers],
    };
}
```

```csharp
namespace MMLib.Alvo.Events.Internal;

/// <summary>
/// The one <see cref="IAlvoEventPump"/>: a manual round of every event dispatcher this build runs, one round at a time.
/// </summary>
/// <remarks>
/// <para>
/// In this build the outbox dispatcher is the only one. HX-03 adds the delivery dispatcher as a second step of the same
/// round and HX-13 the timer and schedule pumps (spec 2026-10-14 §4.15: outbox → fan-out → deliveries → due timers);
/// the public port and its result do not change, and the results of the steps are summed.
/// </para>
/// <para>
/// The gate serialises rounds and is not re-entrant: a round called from inside a round waits for itself, which is why
/// the port says a subscriber must never drain.
/// </para>
/// </remarks>
/// <param name="outbox">The outbox dispatcher, whose manual round checks the mode and the boot before it claims.</param>
internal sealed class EventPump(OutboxDispatcher outbox) : IAlvoEventPump, IDisposable
{
    private readonly SemaphoreSlim _rounds = new(1, 1);

    /// <summary>Gets the outbox dispatcher this pump drives — the same instance the host runs.</summary>
    internal OutboxDispatcher Outbox => outbox;

    /// <inheritdoc/>
    public async Task<AlvoDrainResult> DrainAsync(CancellationToken cancellationToken = default)
    {
        await _rounds.WaitAsync(cancellationToken).ConfigureAwait(false);
        try
        {
            return await outbox.ManualRoundAsync(cancellationToken).ConfigureAwait(false);
        }
        finally
        {
            _rounds.Release();
        }
    }

    /// <inheritdoc/>
    public void Dispose() => _rounds.Dispose();
}
```

```csharp
using System.Diagnostics;

namespace MMLib.Alvo.Events.Internal;

/// <summary>
/// The <c>MMLib.Alvo.Hooks</c> activity source: one consumer span per after-hook action the dispatcher runs.
/// </summary>
/// <remarks>
/// <para>
/// The source spec 2026-10-14 §4.14 names, which host-code hooks and deliveries join as they ship (HX-03, HX-09); a
/// descriptor after-hook's action is the first thing that runs under it. Tags are ids only — the subscriber (the hook's
/// JSON pointer), the event id and type, the outcome — never a URL, a body or an exception message, the same rule the
/// dispatcher's log lines keep.
/// </para>
/// <para>
/// Free when nobody listens: <see cref="ActivitySource.StartActivity(string, ActivityKind)"/> answers
/// <see langword="null"/> without a sampling listener, and both members accept that.
/// </para>
/// </remarks>
internal static class AlvoHookTelemetry
{
    internal const string SourceName = "MMLib.Alvo.Hooks";
    internal const string DeliveryName = "alvo.delivery";
    internal const string SubscriberTag = "alvo.subscriber";
    internal const string EventIdTag = "alvo.event.id";
    internal const string EventTypeTag = "alvo.event.type";
    internal const string OutcomeTag = "alvo.outcome";
    internal const string Succeeded = "succeeded";
    internal const string Failed = "failed";

    private static readonly ActivitySource _source = new(SourceName);

    /// <summary>Starts the span for one run of <paramref name="subscriber"/> over <paramref name="event"/>.</summary>
    internal static Activity? StartDelivery(string subscriber, AlvoEvent @event)
    {
        var delivery = _source.StartActivity(DeliveryName, ActivityKind.Consumer);
        if (delivery is null)
        {
            return null;
        }

        delivery.DisplayName = $"{DeliveryName} {subscriber}";
        delivery.SetTag(SubscriberTag, subscriber);
        delivery.SetTag(EventIdTag, @event.Id.ToString());
        delivery.SetTag(EventTypeTag, @event.Type);

        return delivery;
    }

    /// <summary>Records how the run ended; a failed run also marks the span's status as an error.</summary>
    internal static void Finish(Activity? delivery, string outcome)
    {
        if (delivery is null)
        {
            return;
        }

        delivery.SetTag(OutcomeTag, outcome);
        if (outcome == Failed)
        {
            delivery.SetStatus(ActivityStatusCode.Error);
        }
    }
}
```

```csharp
    /// <remarks>
    /// The failure is rethrown untouched: the span observes it, the entry's release still decides it. A cancellation
    /// while the host stops is neither outcome, exactly as <see cref="DispatchAsync"/> does not count it as an attempt.
    /// </remarks>
    private async Task RunAsync(CompiledAfterHook hook, AlvoEvent @event, CancellationToken stoppingToken)
    {
        using var delivery = AlvoHookTelemetry.StartDelivery(hook.Path, @event);
        try
        {
            await executor.ExecuteAsync(hook, @event, stoppingToken).ConfigureAwait(false);
            AlvoHookTelemetry.Finish(delivery, AlvoHookTelemetry.Succeeded);
        }
        catch when (!stoppingToken.IsCancellationRequested)
        {
            AlvoHookTelemetry.Finish(delivery, AlvoHookTelemetry.Failed);
            throw;
        }
    }
```

```csharp
using Microsoft.Data.Sqlite;
using Microsoft.Extensions.DependencyInjection;

namespace MMLib.Alvo.TestHost.Internal;

/// <summary>
/// One uniquely named <c>Mode=Memory;Cache=Shared</c> SQLite database, kept alive by one open connection for the
/// lifetime of its host.
/// </summary>
/// <remarks>
/// A bare <c>:memory:</c> gives every connection its own empty database, and Alvo's relational driver opens a fresh
/// connection per unit of work — the migration would create tables no request could see. The keep-alive connection is
/// what makes a named shared cache one database, with no file to clean up.
/// </remarks>
internal sealed class InMemorySqlite : IAsyncDisposable, IDisposable
{
    private readonly SqliteConnection _keepAlive;

    private InMemorySqlite(SqliteConnection keepAlive) => _keepAlive = keepAlive;

    /// <summary>Opens a fresh database and registers it as Alvo's provider, through the extension a host calls.</summary>
    internal static InMemorySqlite Open(IAlvoBuilder alvo)
    {
        var keepAlive = new SqliteConnection($"Data Source=alvo-testhost-{Guid.NewGuid():N};Mode=Memory;Cache=Shared");
        keepAlive.Open();
        alvo.UseSqlite(keepAlive.ConnectionString);

        return new InMemorySqlite(keepAlive);
    }

    /// <inheritdoc/>
    public ValueTask DisposeAsync() => _keepAlive.DisposeAsync();

    /// <inheritdoc/>
    public void Dispose() => _keepAlive.Dispose();
}
```

```csharp
using MMLib.Alvo.Events;
using MMLib.Alvo.Migrations;

using GenericHost = Microsoft.Extensions.Hosting.Host;

namespace MMLib.Alvo.TestHost.Internal;

/// <summary>
/// The host behind one <see cref="AlvoTestHost"/>: an empty generic host, Alvo exactly as the caller configured it, a
/// private database unless the caller chose one, manual dispatch, the caller's clock, and webhooks that never leave
/// the process.
/// </summary>
/// <remarks>
/// <para>
/// <b>An empty builder</b>, so no environment variable or <c>appsettings.json</c> of the machine running the tests can
/// change what a test measures; the one configuration value is <c>Alvo:Events:DispatchMode = Manual</c>.
/// </para>
/// <para>
/// <b>A provider is "chosen" when <c>configure</c> registered an <see cref="ISchemaMigrator"/></b> — what
/// <c>UseSqlite</c> and <c>UsePostgreSql</c> both register at the call, and what Alvo's own startup validation reads.
/// </para>
/// <para>
/// The webhook client is configured by the name a host uses to own Alvo's outbound deliveries
/// (<c>docs/architecture/extensibility.md</c>); a fact that delivers to a stub pins the name.
/// </para>
/// </remarks>
internal sealed class TestHostComposition : IAsyncDisposable
{
    private const string WebhookClientName = "MMLib.Alvo.Events.Webhook";

    private static readonly string _dispatchModeKey =
        $"{AlvoEventOptions.SectionName}:{nameof(AlvoEventOptions.DispatchMode)}";

    private readonly InMemorySqlite? _database;
    private bool _started;

    private TestHostComposition(IHost host, InMemorySqlite? database)
    {
        Host = host;
        _database = database;
    }

    /// <summary>Gets the composed host.</summary>
    internal IHost Host { get; }

    /// <summary>Composes the host; nothing runs until <see cref="StartAsync"/>.</summary>
    internal static TestHostComposition Build(
        Action<IAlvoBuilder> configure, TimeProvider? time, HttpMessageHandler? webhooks)
    {
        var builder = GenericHost.CreateEmptyApplicationBuilder(new HostApplicationBuilderSettings());
        builder.Configuration.AddInMemoryCollection([new(_dispatchModeKey, nameof(AlvoEventDispatchMode.Manual))]);
        if (time is not null)
        {
            builder.Services.AddSingleton(time);
        }

        var alvo = builder.Services.AddAlvo(configure);
        var database = HasProvider(builder.Services) ? null : InMemorySqlite.Open(alvo);
        RouteWebhooks(builder.Services, webhooks);

        return new TestHostComposition(Built(builder, database), database);
    }

    /// <summary>Builds the host, closing the database already opened for it when the build itself throws.</summary>
    private static IHost Built(HostApplicationBuilder builder, InMemorySqlite? database)
    {
        try
        {
            return builder.Build();
        }
        catch
        {
            database?.Dispose();
            throw;
        }
    }

    /// <summary>Starts the host and insists its boot reached Ready.</summary>
    /// <exception cref="InvalidOperationException">The host started but the boot did not reach Ready.</exception>
    internal async Task StartAsync(CancellationToken cancellationToken)
    {
        await Host.StartAsync(cancellationToken).ConfigureAwait(false);
        _started = true;

        var boot = Host.Services.GetRequiredService<AlvoBootState>();
        if (boot.Phase is not AlvoBootPhase.Ready)
        {
            throw NotReady(boot);
        }
    }

    /// <inheritdoc/>
    public async ValueTask DisposeAsync()
    {
        if (_started)
        {
            await Host.StopAsync(CancellationToken.None).ConfigureAwait(false);
        }

        Host.Dispose();
        if (_database is not null)
        {
            await _database.DisposeAsync().ConfigureAwait(false);
        }
    }

    private static bool HasProvider(IServiceCollection services) =>
        services.Any(descriptor => descriptor.ServiceType == typeof(ISchemaMigrator));

    private static void RouteWebhooks(IServiceCollection services, HttpMessageHandler? webhooks) =>
        services.AddHttpClient(WebhookClientName).ConfigurePrimaryHttpMessageHandler(
            () => webhooks is null ? new NoWebhookReceiver() : new SharedReceiver(webhooks));

    private static InvalidOperationException NotReady(AlvoBootState boot) => new(
        $"The test host started, but its boot ended {boot.Phase} rather than Ready, so there is no schema to test "
        + $"against: {boot.Failure ?? "the boot recorded no reason"}. An AlvoTestHost needs FromDescriptor.");
}
```

```csharp
    private bool _disposed;

        Data = composition.Host.Services.GetRequiredService<IAlvoData>();
    }

    public IAlvoData Data { get; }
```

```csharp
using System.Collections.Concurrent;
using System.Net;

namespace MMLib.Alvo.TestHost.Tests;

/// <summary>
/// A webhook receiver that keeps every body it was sent and answers 200 — and, when told to, writes back first
/// (spec 2026-10-14 Appendix A R-12).
/// </summary>
/// <remarks>
/// <para>
/// <b>The write-back runs as an out-of-process receiver's would: with the execution context not flowing.</b> In process,
/// the stub runs inside the dispatcher's async flow, and from HX-03 on a dispatcher sets the ambient chain depth
/// (<c>AlvoFlow</c>, spec 2026-10-14 §4.6: envelope depth + 1) for each run. A write-back inheriting it would climb one
/// level per round and be refused at depth 9, the drain would go quiet, and the loop fact would fail although a real
/// receiver — writing back over HTTP, at depth 0 — loops forever. Suppressing the flow keeps the fact about the real
/// loop; do not "fix" a failing loop fact in HX-03 by deleting this.
/// </para>
/// <para>
/// <b>It refuses to work once disposed</b>, so a host that disposed a caller's handler is caught by the fact that reuses
/// one across hosts rather than passing because a disposed handler kept answering.
/// </para>
/// </remarks>
internal sealed class StubWebhookReceiver : HttpMessageHandler
{
    private readonly ConcurrentQueue<string> _deliveries = new();

    /// <summary>Gets or sets what the receiver does on every delivery before it answers.</summary>
    internal Func<Task>? OnDelivery { get; set; }

    /// <summary>Gets every body received, in arrival order.</summary>
    internal IReadOnlyList<string> Deliveries => [.. _deliveries];

    /// <summary>Gets whether anything disposed this receiver.</summary>
    internal bool IsDisposed { get; private set; }

    /// <inheritdoc/>
    protected override async Task<HttpResponseMessage> SendAsync(
        HttpRequestMessage request, CancellationToken cancellationToken)
    {
        ObjectDisposedException.ThrowIf(IsDisposed, this);

        _deliveries.Enqueue(await request.Content!.ReadAsStringAsync(cancellationToken));
        if (OnDelivery is { } onDelivery)
        {
            await OutOfProcess(onDelivery);
        }

        return new HttpResponseMessage(HttpStatusCode.OK);
    }

    /// <inheritdoc/>
    protected override void Dispose(bool disposing)
    {
        IsDisposed = true;
        base.Dispose(disposing);
    }

    private static Task OutOfProcess(Func<Task> work)
    {
        using (ExecutionContext.SuppressFlow())
        {
            return Task.Run(work);
        }
    }
}
```

```csharp
/// <summary>The rounds one drain ran: their total, and the subscribers of the most recent ones.</summary>
internal sealed class DrainProgress
{
    /// <summary>How many of the last rounds name a loop; a cycle of up to this many subscribers is named whole.</summary>
    internal const int LoopWindow = 10;

    private readonly List<AlvoDrainResult> _rounds = [];

    /// <summary>Records one non-quiet round.</summary>
    internal void Add(AlvoDrainResult round) => _rounds.Add(round);

    /// <summary>Every recorded round summed, subscribers distinct in first-run order.</summary>
    internal AlvoDrainResult Total() => new()
    {

        Failed = _rounds.Sum(round => round.Failed),
        Subscribers = Distinct(_rounds),
    };

    /// <summary>The subscribers of the last <see cref="LoopWindow"/> rounds.</summary>
    internal IReadOnlyList<string> Recent() => Distinct(_rounds.TakeLast(LoopWindow));

    private static string[] Distinct(IEnumerable<AlvoDrainResult> rounds) =>
        [.. rounds.SelectMany(round => round.Subscribers).Distinct(StringComparer.Ordinal)];
```

```csharp
    /// Delivers what is queued, round after round, until a round finds nothing due — including the events the
    /// deliveries themselves cause.
    /// </summary>
    /// <remarks>
    /// Each round is one tick of the production dispatchers: the same hooks, the same retry backoff on the host's clock.
    /// Under a <c>FakeTimeProvider</c> a failed attempt waits out its backoff, so the drain returns with it counted in
    /// <see cref="AlvoDrainResult.Failed"/>; advance the clock and drain again to retry it. Under the system clock a drain
    /// that runs longer than the backoff retries it again — pass a fake clock whenever a delivery can fail.
    /// </remarks>
    /// <param name="cancellationToken">Cancels the drain between or inside rounds.</param>
    /// <returns>Every non-quiet round summed: entries claimed, attempts failed, subscribers run.</returns>
    /// <exception cref="AlvoDrainNotQuiescentException">The queue was still busy after 100 rounds.</exception>
    public async Task<AlvoDrainResult> DrainEventsAsync(CancellationToken cancellationToken = default)
    {
        var progress = new DrainProgress();
        for (var round = 0; round < MaxRounds; round++)
        {
            var result = await _pump.DrainAsync(cancellationToken).ConfigureAwait(false);
            if (result.IsQuiet)
            {
                return progress.Total();
            }

            progress.Add(result);
        }

        throw AlvoDrainNotQuiescentException.After(MaxRounds, progress.Recent());
    }
```

```csharp
using System.Collections.Concurrent;
using System.Diagnostics;

namespace MMLib.Alvo.TestHost;

/// <summary>
/// Records which hooks and subscribers ran inside one <see cref="AlvoTestHost"/>, read off Alvo's
/// <c>MMLib.Alvo.Hooks</c> activity source.
/// </summary>
/// <remarks>
/// <para>
/// In this build what runs there is a descriptor after-hook's action during <see cref="AlvoTestHost.DrainEventsAsync"/>,
/// named by its JSON pointer, such as <c>/entities/tickets/hooks/afterCreate/0</c>; host-code extensions join under
/// their own ids as they ship. A run counts unless it failed: a failed attempt is not a run, a run cut short by the host
/// stopping (no outcome) is not either, and any other outcome — a write hook that rejects, from HX-09 on — is.
/// </para>
/// <para>
/// The activity source is process-wide, so the recorder keeps only what ran inside its own host's drains: several hosts
/// in one test run never see each other's runs.
/// </para>
/// </remarks>
public sealed class AlvoHookRecorder
{
    internal const string HooksSourceName = "MMLib.Alvo.Hooks";
    internal const string DrainSourceName = "MMLib.Alvo.TestHost";

    private const string SubscriberTag = "alvo.subscriber";
    private const string OutcomeTag = "alvo.outcome";
    private const string Failed = "failed";

    private readonly ConcurrentDictionary<ActivityTraceId, byte> _drains = new();
    private readonly ConcurrentQueue<(string Id, string? Outcome)> _runs = new();
    private readonly ActivityListener _listener;

    internal AlvoHookRecorder()
    {
        _listener = new ActivityListener
        {
            ShouldListenTo = source => source.Name is HooksSourceName or DrainSourceName,
            Sample = (ref ActivityCreationOptions<ActivityContext> _) => ActivitySamplingResult.AllDataAndRecorded,
            ActivityStopped = Record,
        };
        ActivitySource.AddActivityListener(_listener);
    }

    /// <summary>Asserts that <paramref name="id"/> ran exactly <paramref name="times"/> times, failed attempts not counted.</summary>
    /// <param name="id">The hook or subscriber id; for a descriptor after-hook, its JSON pointer.</param>
    /// <param name="times">How many runs are expected; <c>0</c> asserts it never ran.</param>
    /// <exception cref="InvalidOperationException">It ran a different number of times; the message lists every run.</exception>
    public void AssertRan(string id, int times = 1)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(id);
        ArgumentOutOfRangeException.ThrowIfNegative(times);

        var ran = _runs.Count(run => run.Id == id && run.Outcome is { } outcome && outcome != Failed);
        if (ran != times)
        {
            throw Mismatch(id, times, ran);
        }
    }

    /// <summary>Claims every activity of the drain whose root trace is <paramref name="drain"/> for this host.</summary>
    internal void Track(ActivityTraceId drain) => _drains.TryAdd(drain, 0);

    /// <summary>Stops listening.</summary>
    internal void Stop() => _listener.Dispose();

    private void Record(Activity activity)
    {
        if (activity.Source.Name == HooksSourceName
            && _drains.ContainsKey(activity.TraceId)
            && activity.GetTagItem(SubscriberTag) is string id)
        {
            _runs.Enqueue((id, activity.GetTagItem(OutcomeTag) as string));
        }
    }

    private InvalidOperationException Mismatch(string id, int expected, int actual) => new(
        $"Expected '{id}' to run {expected} time(s), but it ran {actual}. Recorded runs: {Described()}.");

    private string Described() =>
        _runs.IsEmpty ? "none" : string.Join(", ", _runs.Select(run => $"{run.Id} ({run.Outcome})"));
}
```
