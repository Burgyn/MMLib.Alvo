Fields — one look for every text input

Lowercase letters, digits and underscores; it becomes the table's name.
Where the sign-in link is sent. That is not an email address the store accepts.
  • Name above the box, at --text-sm in --dim; never floating, never in a notch. One name only.
  • Box: 1 px --border, --border2 on hover, the focus ring on the frame, the buttons' corner.
  • Text at --text-sm, and 16 px on a phone, where iOS would otherwise zoom into the field.
  • Required: an accent * the stylesheet draws with empty alternative text; aria-required on the control.
  • Field error (FieldRefusals): after the hint, in --danger-fg; the box is aria-invalid, its border turns, its aria-describedby lists hint then refusal, and a failed submit moves focus to it. A refusal no field owns is the ErrorPanel.
  • Read-only is text, not a greyed box.

Wrappers: the pattern language, implemented once

The screens are drawn with MudBlazor 9.10.0, imported beneath this stylesheet's layers. These five Alvo components carry the policy the library cannot set globally; every screen uses them rather than the library directly for these jobs (docs/superpowers/specs/2026-09-24-f5-admin-mudblazor-design.md §3). None takes a MudBlazor type as a parameter. The command palette is the library's dialog at the top of the page, so it is not drawn here either.

ComponentUse it forWhat it guarantees
AlvoEditorCreating or editing one item with more than one value Right-hand modal side sheet; focus on the first field; Escape and Cancel ask “Discard your changes?” when dirty; Enter and Ctrl/Cmd+Enter submit; the submit is busy and cannot run twice.
AlvoConfirmAny destructive action Centred; no light dismiss; Escape = Cancel; the button names the verb; TypeToConfirm for an irreversible, wide-blast one (destructive apply, rollback).
AlvoAlertState, and every error role=alert for errors and warnings, role=status otherwise; takes focus after a failed submit. Errors are never snackbars.
AlvoButtonEvery button Four tones (Primary, Secondary, Danger, Ghost); no ripple, shadow or uppercase; Busy disables it and shows progress.
AlvoThemeThe library’s palette Both themes from this stylesheet’s tokens (pinned equal by AlvoMudThemeTests); dark is scoped to [data-theme=dark], written before paint by alvo.js.
